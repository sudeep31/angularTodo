9.1

A11yModule Overview

Angular CDK's @angular/cdk/a11y module provides battle-tested, spec-compliant accessibility primitives that you should use instead of building focus traps, live region announcements, and keyboard navigation from scratch.

✅

Angular 21 — standalone, no NgModule needed. All CDK A11y directives and services are importable directly: import { cdkTrapFocus, LiveAnnouncer } from '@angular/cdk/a11y'. No A11yModule import required in Angular 21 standalone components.

Installation

Terminal
ng add @angular/cdk

Core Services & Directives

Primitive Type Purpose
cdkTrapFocus Directive Trap keyboard focus inside a container (modal dialogs)
FocusTrapFactory Service Programmatically create / destroy focus traps
LiveAnnouncer Service Announce messages to screen readers via live region
FocusMonitor Service Track focus origin (mouse, keyboard, touch, programmatic)
HighContrastModeDetector Service Detect Windows high contrast / forced colors mode
CdkListbox / CdkOption Directive Accessible listbox with roving tabindex, keyboard nav
CdkMenu / CdkMenuItem Directive Accessible menu and menu bar patterns (APG compliant)
ActiveDescendantKeyManager Service Manage keyboard navigation for aria-activedescendant patterns
9.2

FocusTrap & cdkTrapFocus

cdkTrapFocus
@angular/cdk/a11y · Directive
Directive

Traps Tab and Shift+Tab keyboard navigation inside a container element. Essential for modal dialogs, drawers, and any overlay that must contain focus. Use cdkTrapFocusAutoCapture to move focus into the trap immediately on initialization.

HTML — modal dialog with focus trap
<div
  role="dialog"
  aria-modal="true"
  [attr.aria-labelledby]="dialogTitleId()"
  cdkTrapFocus
  cdkTrapFocusAutoCapture>
  <h2 [id]="dialogTitleId()">Confirm Deletion</h2>
  <p>Are you sure you want to delete this todo?</p>
  <button type="button" (click)="confirm()">Delete</button>
  <button type="button" (click)="cancel()">Cancel</button>
</div>
TypeScript — programmatic FocusTrap with signals
import { Component, inject, signal, effect, ElementRef, viewChild } from '@angular/core';
import { FocusTrapFactory, FocusTrap } from '@angular/cdk/a11y';

@Component({ selector: 'app-drawer', standalone: true, /* ... */ })
export class DrawerComponent {
  private focusTrapFactory = inject(FocusTrapFactory);
  private drawerRef = viewChild<ElementRef>('drawerPanel');
  private focusTrap: FocusTrap | null = null;
  readonly isOpen = signal(false);

  constructor() {
    effect(() => {
      if (this.isOpen()) {
        this.focusTrap = this.focusTrapFactory.create(this.drawerRef()!.nativeElement);
        this.focusTrap.focusInitialElementWhenReady();
      } else {
        this.focusTrap?.destroy();
        this.focusTrap = null;
      }
    });
  }
}
⚠️

iOS VoiceOver caveat: cdkTrapFocus traps DOM focus (keyboard), but VoiceOver cursor is independent. Add aria-modal="true" on the dialog element and set [inert] on background content to prevent VoiceOver users from swiping outside the modal.

9.3

LiveAnnouncer

LiveAnnouncer
@angular/cdk/a11y · Service (injectable)
Service

Announces messages to screen readers via an invisible live region that CDK manages globally. Preferred over custom live regions because CDK handles the timing, DOM management, and cross-browser quirks automatically.

TypeScript — announce with politeness and optional clear
import { inject, Component } from '@angular/core';
import { LiveAnnouncer } from '@angular/cdk/a11y';

@Component({ /* ... */ })
export class TodoListComponent {
  private announcer = inject(LiveAnnouncer);

  addTodo(text: string) {
    // ... add logic ...
    this.announcer.announce(`Todo added: ${text}`, 'polite');
  }

  deleteTodo(text: string) {
    // ... delete logic ...
    this.announcer.announce(`Todo deleted: ${text}`, 'assertive');
  }

  onSearchResults(count: number) {
    this.announcer.announce(
      count === 0 ? 'No results found' : `${count} results found`,
      'polite',
      300 // duration in ms before CDK clears the region
    );
  }
}

Route Change Announcements

TypeScript — custom TitleStrategy for SPA navigation
import { inject, Injectable } from '@angular/core';
import { TitleStrategy, RouterStateSnapshot } from '@angular/router';
import { Title } from '@angular/platform-browser';
import { LiveAnnouncer } from '@angular/cdk/a11y';

@Injectable({ providedIn: 'root' })
export class A11yTitleStrategy extends TitleStrategy {
  private title = inject(Title);
  private announcer = inject(LiveAnnouncer);

  override updateTitle(snapshot: RouterStateSnapshot): void {
    const pageTitle = this.buildTitle(snapshot) ?? 'Angular App';
    this.title.setTitle(pageTitle);
    this.announcer.announce(`Navigated to: ${pageTitle}`, 'polite');
  }
}
TypeScript — app.config.ts provider
import { TitleStrategy } from '@angular/router';
import { A11yTitleStrategy } from './a11y-title.strategy';

export const appConfig = {
  providers: [
    { provide: TitleStrategy, useClass: A11yTitleStrategy }
  ]
};
9.4

FocusMonitor

FocusMonitor
@angular/cdk/a11y · Service (injectable)
Service

Tracks how an element received focus — keyboard, mouse, touch, or program. This is the correct way to implement the :focus-visible behaviour in Angular components. The CDK automatically applies CSS classes (cdk-focused, cdk-keyboard-focused, etc.) to monitored elements.

TypeScript — signal-based focus origin
import { inject, Component, signal, OnDestroy, viewChild, ElementRef } from '@angular/core';
import { FocusMonitor, FocusOrigin } from '@angular/cdk/a11y';

@Component({ /* standalone, OnPush, ... */ })
export class CustomButtonComponent implements OnDestroy {
  private focusMonitor = inject(FocusMonitor);
  private buttonRef = viewChild<ElementRef>('btn');
  readonly focusOrigin = signal<FocusOrigin>(null);

  ngAfterViewInit() {
    this.focusMonitor.monitor(this.buttonRef()!.nativeElement)
      .subscribe(origin => this.focusOrigin.set(origin));
  }

  ngOnDestroy() {
    this.focusMonitor.stopMonitoring(this.buttonRef()!.nativeElement);
  }
}
HTML — conditionally show visible focus ring
<button
  #btn
  type="button"
  [class.keyboard-focus]="focusOrigin() === 'keyboard'">
  Save Todo
</button>
ℹ️

CDK automatically adds cdk-focused and cdk-keyboard-focused CSS classes to monitored elements. You can style .cdk-keyboard-focused in your CSS instead of managing it manually in the component template.

9.5

HighContrastModeDetector

HighContrastModeDetector
@angular/cdk/a11y · Service (injectable)
Detection

Detects whether the user is running Windows High Contrast Mode (now called Forced Colors Mode in the CSS spec). Returns 'black-on-white', 'white-on-black', or 'none'. Use this to conditionally add high-contrast-safe styles in components that rely on colour to convey meaning.

TypeScript
import { inject, Component } from '@angular/core';
import { HighContrastModeDetector } from '@angular/cdk/a11y';

@Component({ /* ... */ })
export class StatusBadgeComponent {
  private hcDetector = inject(HighContrastModeDetector);
  readonly isHighContrast = this.hcDetector.getHighContrastMode() !== 'none';
}
⚠️

Prefer CSS forced-colors media query over JS detection when possible. Use @media (forced-colors: active) in your CSS to ensure components remain usable in High Contrast Mode. The JS detector is useful for conditionally rendering alternative text-based indicators where colour alone carries meaning.

9.6

CdkListbox

CdkListbox / CdkOption
@angular/cdk/listbox · Directive
Directive

A fully accessible listbox implementation — handles roving tabindex, Arrow key navigation, Home/End, Space selection, and aria-selected state management automatically. Supports both single and multi-select modes.

TypeScript — import
import { CdkListbox, CdkOption } from '@angular/cdk/listbox';

@Component({
  imports: [CdkListbox, CdkOption],
  changeDetection: ChangeDetectionStrategy.OnPush,
})
HTML — single-select listbox
<ul
  cdkListbox
  aria-label="Select priority"
  [cdkListboxValue]="selectedPriority()"
  (cdkListboxValueChange)="selectedPriority.set($event.value)">
  @for (option of priorities(); track option.value) {
    <li
      cdkOption
      [cdkOptionValue]="option.value">
      {{ option.label }}
    </li>
  }
</ul>
✅

CdkListbox automatically applies role="listbox" and role="option", manages aria-selected, and implements the full APG Listbox keyboard contract. You get full ARIA compliance with zero manual ARIA attribute management.

9.7

CdkMenu & CdkMenuBar

CdkMenu / CdkMenuItem / CdkMenuBar
@angular/cdk/menu · Directive
Directive

Full APG Menu pattern implementation — handles role="menu", role="menuitem", role="menubar", aria-haspopup, aria-expanded, arrow key navigation, Escape to close, and sub-menu support. Use CdkMenuTriggerFor to connect a trigger button to its menu panel.

TypeScript — import
import {
  CdkMenu, CdkMenuItem, CdkMenuTriggerFor, CdkMenuBar
} from '@angular/cdk/menu';
HTML — context menu trigger + panel
<button
  type="button"
  [cdkMenuTriggerFor]="actionsMenu"
  aria-label="Todo actions">
  Actions ▾
</button>

<ng-template #actionsMenu>
  <div cdkMenu>
    <button cdkMenuItem (click)="editTodo()">Edit</button>
    <button cdkMenuItem (click)="duplicateTodo()">Duplicate</button>
    <button cdkMenuItem (click)="deleteTodo()">Delete</button>
  </div>
</ng-template>
✅

CdkMenuTriggerFor automatically manages aria-haspopup="menu" and aria-expanded on the trigger button. CdkMenu manages all keyboard navigation and Escape handling — zero manual event listeners needed.

9.8

ActiveDescendantKeyManager

ActiveDescendantKeyManager
@angular/cdk/a11y · Service class
Service

Manages keyboard navigation for aria-activedescendant patterns — where the parent container holds focus and aria-activedescendant points to the currently active child item. Used for combobox autocomplete dropdowns, search suggestion lists, and other composite widgets where the input field (not the options) must maintain DOM focus.

TypeScript — combobox with ActiveDescendantKeyManager
import { inject, Component, signal, viewChildren, QueryList } from '@angular/core';
import { ActiveDescendantKeyManager, Highlightable } from '@angular/cdk/a11y';

// 1. Options must implement Highlightable
@Component({ selector: '[app-option]', /* ... */ })
export class OptionComponent implements Highlightable {
  readonly isActive = signal(false);
  setActiveStyles()   { this.isActive.set(true);  }
  setInactiveStyles() { this.isActive.set(false); }
}

// 2. Parent manages key navigation
@Component({ /* ... */ })
export class AutocompleteComponent {
  readonly options = viewChildren(OptionComponent);
  private keyManager!: ActiveDescendantKeyManager<OptionComponent>;

  ngAfterViewInit() {
    this.keyManager = new ActiveDescendantKeyManager(this.options())
      .withWrap().withTypeAhead();
  }

  onKeydown(e: KeyboardEvent) {
    this.keyManager.onKeydown(e);
  }

  getActiveOptionId(): string | undefined {
    return this.keyManager.activeItem?.id;
  }
}

CDK A11y Primitives Summary Table

Primitive Import Path ARIA Pattern When to Use
cdkTrapFocus @angular/cdk/a11y Modal Dialog, Drawer Any overlay that must contain keyboard focus
FocusTrapFactory @angular/cdk/a11y Programmatic focus trap When cdkTrapFocus directive is insufficient (dynamic overlays)
LiveAnnouncer @angular/cdk/a11y ARIA Live Regions Route changes, dynamic updates, notifications, search result counts
FocusMonitor @angular/cdk/a11y Focus Visible / :focus-visible Custom components needing keyboard vs mouse focus styling differentiation
HighContrastModeDetector @angular/cdk/a11y Forced Colors Mode Components using colour-only indicators that must adapt to Windows HC Mode
CdkListbox / CdkOption @angular/cdk/listbox Listbox (APG) Single or multi-select custom list replacements
CdkMenu / CdkMenuItem @angular/cdk/menu Menu / Menu Bar (APG) Context menus, action menus, navigation menu bars
ActiveDescendantKeyManager @angular/cdk/a11y Combobox / Autocomplete Widgets where focus stays on input and aria-activedescendant tracks active option
ListKeyManager @angular/cdk/a11y Roving Tabindex Custom composite widgets where actual DOM focus moves between items
